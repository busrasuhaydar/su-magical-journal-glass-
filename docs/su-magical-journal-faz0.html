Kişisel yaşam, sanat kariyeri ve proje yönetimi için tek bir akıllı sistem

Bu sayfa Faz 0 teslimidir: rakip araştırması, mimari, veri şeması, akışlar, tasarım sistemi ve yol haritası. Onayınızdan sonra Faz 1 kodlamasına geçilecek.

React 18 + TypeScript + Vite Supabase · PostgreSQL · RLS Edge Functions + pg_cron kuyruğu Claude API (sunucu tarafı) PWA · Europe/Istanbul · tr-TR

Temel mimari kararlar

Tek kayıt, her yerde görünüm

Her bilgi tek tabloda tek satırdır. Takvim, günlük sayfa, proje takvimi ve ana sayfa bu satırları SQL görünümleri üzerinden okur. Kopya yoktur, durum değişince her ekran aynı anda güncellenir.

Takvim bir tablo değil, bir görünüm

v_calendar_entries görünümü görevleri, etkinlikleri, paylaşımları, başvuru tarihlerini ve resmî tatilleri tek akışta birleştirir. Takvim kendi verisini saklamaz.

Geçmiş asla üzerine yazılmaz

Her değişiklik change_log tablosuna tetikleyiciyle yazılır. Zaman Makinesi ve Proje Hafızası bu değişmez kayıttan beslenir.

Yapay zekâ öneri yapar, karar vermez

AI'nın ürettiği her şey önce ai_suggestions tablosuna "onay bekliyor" olarak düşer. Tarih, para ve yayın gibi kayıtlar ancak sizin onayınızla oluşur.

Bölüm 22 · Rakip araştırmasıAltı referans platform

Gesso, Artlogic, Project App, Buffer ve Morph AI resmî sitelerinden 22 Kasım 2026'da okundu. Artwork Archive sitesi otomatik erişimi engelledi (HTTP 403); o sütundaki bilgiler önceki genel bilgiye dayanıyor ve "çıkarım" olarak işaretlendi.

BulgularBenimseyeceklerimiz, iyileştireceklerimiz, farkımız

Benimsenecek

  • Gesso: fırsat kartında ücret, durum, son tarih yan yana
  • Gesso Pro: duyuru e-postasını sisteme iletme fikri → Faz 3'te "yapıştır / PDF / bağlantı"
  • Project App: Yaşam Alanı → Proje → Görev hiyerarşisi, zaman blokları
  • Buffer: fikir → taslak → kuyruk akışı, pano görünümü, "bildirimle yayınla" yedeği
  • Morph AI: belge/görsel/ses girdisinden yapılandırılmış etkinlik
  • Artlogic: kişi ↔ teklif ↔ eser bağlantısı

İyileştirilecek

  • Hiçbiri sosyal içeriği projeye bağlamıyor; burada her paylaşım bir projenin zaman çizelgesinde yaşar
  • Fırsat araçları hazırlık görevi üretmiyor; burada şartlardan geriye planlanmış görev listesi çıkar
  • AI çıkarımında belirsizlik gösterilmiyor; burada her alanın güven puanı ve kaynak alıntısı var
  • Geçmiş kayıt yok; burada değişmez değişiklik günlüğü var
  • Türkçe arayüz ve TR resmî tatilleri hiçbirinde yok

Gerçek farklılaşma

  • Bağlam grafiği: her kayıt diğerlerine bağlanabilir, tek dosya birden çok projede
  • Zaman Makinesi: herhangi bir günün tam fotoğrafı, geçen yılın aynı günü
  • Proje Hafızası: "Nerede kaldın?" özeti, karar geçmişiyle
  • Çakışma Zekâsı: aynı haftaya düşen son tarihler, aşırı yüklü dönemler, duraklayan projeler
  • Duyurudan plana: tek yapıştırmayla fırsat + tarihler + görevler + hatırlatıcılar

Çekirdek tablolar (kısaltılmış)

-- Ortak: her tabloda id, owner_id, created_at, updated_at, deleted_at
create table projects (id uuid pk, owner_id uuid not null, title text, slug text unique,
  status project_status, priority priority, start_date date, target_date date,
  color text, description text, objectives jsonb, progress_override numeric);
create table tasks (id uuid pk, project_id uuid references projects, contact_id uuid references contacts,
  opportunity_id uuid references opportunities, title text not null, description text,
  starts_at timestamptz, ends_at timestamptz, all_day bool, priority priority, category text,
  status task_status -- todo|doing|done|postponed|cancelled, rrule text, completed_at timestamptz,
  postponed_from uuid references tasks, source text -- manual|ai|template);
create table events (id uuid pk, project_id uuid, kind event_kind -- meeting|exhibition|fair|personal|...,
  title text, starts_at timestamptz, ends_at timestamptz, location text, rrule text);
create table social_posts (id uuid pk, project_id uuid references projects, content_type text,
  caption_tr text, caption_en text, hashtags text[], links text[], status post_status,
  scheduled_at timestamptz);
create table post_targets (id uuid pk, post_id uuid references social_posts on delete cascade,
  platform platform -- instagram|x|youtube|website, account_id uuid, status post_status,
  published_url text, external_id text, error text, unique(post_id, platform));
create table opportunities (id uuid pk, title text, organization text, gallery text, city text, country text,
  fee_amount numeric, fee_currency currency, requirements jsonb, required_docs jsonb, artwork_reqs jsonb,
  application_url text, contact jsonb, notes text, status opp_status, is_confirmed bool,
  source_text text, source_url text, source_file_id uuid, extraction jsonb -- alan başına güven + alıntı);
create table opportunity_dates (id uuid pk, opportunity_id uuid, kind opp_date_kind
  -- app_open|deadline|announcement|delivery|install|opening|closing, date_value timestamptz,
  certainty certainty -- confirmed|uncertain|conflicting, evidence text);
create table files (id uuid pk, storage_path text unique, mime text, size bigint, sha256 text unique, title text);
create table entity_links (id uuid pk, from_type entity_type, from_id uuid, to_type entity_type, to_id uuid,
  relation text, unique(from_type, from_id, to_type, to_id, relation));
create table change_log (id bigserial pk, owner_id uuid, table_name text, row_id uuid, op text,
  before jsonb, after jsonb, at timestamptz default now()); -- yalnız INSERT izni
create table memory_entries (id uuid pk, project_id uuid, kind memory_kind
  -- idea|goal|decision|feature_added|feature_removed|problem|solution|reference|state|next_step,
  body text, supersedes uuid references memory_entries, decided_on date, evidence_ref jsonb);
-- Ayrıca: contacts, interactions, project_contacts, project_opportunities, applications, application_docs,
-- reminders, notifications, journal_days, journal_blocks, ideas, finance_entries, fx_rates,
-- holidays, social_accounts (token Vault'ta), publish_jobs, ai_suggestions, project_stages

-- Takvim: tek görünüm, kopya yok
create view v_calendar_entries as
  select 'task' kind, id, project_id, title, starts_at, ends_at, status::text from tasks where deleted_at is null
  union all select 'event', id, project_id, title, starts_at, ends_at, kind::text from events ...
  union all select 'post', id, project_id, coalesce(caption_tr, caption_en), scheduled_at, scheduled_at, status::text from social_posts ...
  union all select 'opportunity_date', d.id, ..., d.date_value, d.date_value, d.kind::text from opportunity_dates d ...
  union all select 'holiday', id, null, name, day::timestamptz, day::timestamptz, kind from holidays;
Proje ilerlemesi varsayılan olarak hesaplanır: tamamlanan görev ağırlığı / toplam (iptal edilenler hariç) ve tamamlanan aşamalar. Elle değer girerseniz progress_override kullanılır ve bu açıkça gösterilir.

Senkron kuralları

  • İstemci yazar → PostgreSQL → Realtime yayını → ilgili sorgu anahtarları (ör. ['calendar', '2027-04'], ['project', id]) geçersiz kılınır. Tüm ekranlar aynı satırı tekrar okur.
  • Yayın durumu yalnız sunucu (Edge Function) tarafından değiştirilir; istemci "Yayınla" isteği gönderir, sonucu Realtime ile görür.
  • Çift kayıt önlemi: dosyada sha256 unique, bağlantılarda bileşik unique, AI çıkarımında kaynak URL + başlık benzerlik kontrolü ("Bu fırsat zaten var mı?").
  • Çevrim dışı (Faz 6): değişiklikler IndexedDB kuyruğunda bekler, bağlantı gelince sırayla gönderilir; updated_at çakışmasında kullanıcıya sorulur.

  • Hata: kırmızı kenar + ne olduğunu ve nasıl düzeltileceğini söyleyen Türkçe metin

İkonlar ve süsler

  • Lucide ikonları, 1.75 çizgi, 18/20 px, köşeleri yuvarlatılmış
  • Yıldız ve parıltı ekran başına en fazla 2–3, yalnız boş alanda
  • Kitap, kurdele, ayraç: kenar çubuğu, boş durum ve Zaman Makinesi'nde

Grafikler

  • Recharts; ince ızgara, alan dolgusu %15, uç nokta vurgulu
  • Seri renkleri sabit sırayla: gül, turkuaz, şeftali, leylak, okyanus
  • Para birimi ve yüzde tr-TR biçiminde, eksen etiketleri gerçek değerler

12 · Güvenlik ve yedeklemeVerileriniz yalnız sizin

Erişim

  • Supabase Auth: e-posta + şifre veya sihirli bağlantı, isteğe bağlı TOTP 2FA
  • Her tabloda RLS: owner_id = auth.uid()
  • change_log: yalnız ekleme, güncelleme/silme yasak
  • Storage kovaları özel; dosyalar kısa ömürlü imzalı URL ile açılır
  • Yüklemede MIME ve boyut kontrolü (görsel 25 MB, video 1 GB, ses 100 MB)

Sırlar

  • OAuth erişim/yenileme tokenları Supabase Vault'ta şifreli
  • AI ve e-posta anahtarları Edge Function sırlarında
  • İstemci paketinde yalnız herkese açık "anon" anahtar

Yedek ve geri yükleme

  • Supabase günlük yedekleri (Pro planda zamanda geri dönüş)
  • Haftalık otomatik JSON dışa aktarım, özel kovaya
  • Ayarlar → "Tüm verilerimi indir" (JSON + dosya listesi)
  • Geri yükleme: önce önizleme, sonra onayla birleştir; kimlikler korunur

Onay gerektiren işlemler

  • Silme (önce çöp kutusu, 30 gün), toplu değişiklik
  • Yayın zamanlama ve "Şimdi yayınla"
  • AI önerilerinin uygulanması, tarih ve finans değişiklikleri
  • Dış hesap bağlama ve bağlantı kesme

13 · Geliştirme yol haritasıHer fazın sonunda test edilmiş, çalışan ürün

Faz 1Çekirdek

Teslim: Supabase projesi ve göçler, Auth, tasarım sistemi bileşenleri, Türkçe arayüz, gerçek 2027 takvimi (yıl/ay/hafta/gün/ajanda), resmî tatiller, Ana Sayfa, görevler (tekrar, erteleme), günlük plan 08:00–23:00 sürükle-bırak, günlük sayfa (foto, ses, bağlantı kartı, galeri), dosya yönetimi.

Kabul testi: 2027'nin her ayının gün sayısı ve hafta başlangıcı doğru; görev sürüklenince takvimde, günlük sayfada ve ana sayfada aynı anda değişir; sayfa yenilenince veri kalır.

Faz 2Projeler

Proje çalışma alanı (17 sekme), Kanban/liste/zaman çizelgesi, proje takvimi, projeye bağlı sosyal içerik (elle yayın), CRM, fikirler → projeye dönüştürme, Proje Hafızası kayıtları.

Kabul testi: projeden oluşturulan içerik merkezde tek kayıt olarak görünür; bir dosya iki projede, tek yükleme.

Faz 3Fırsatlar

Sergiler ve Fırsatlar merkezi, 10 durumlu hat, duyuru/PDF/bağlantı çıkarımı, belirsizlik işaretleri, otomatik takvim tarihleri, hazırlık görevleri, özelleştirilebilir hatırlatıcılar.

Kabul testi: gerçek bir open call metni yapıştırılır; uydurma tarih oluşmaz, eksikler "bilinmiyor" olarak işaretlenir.

Faz 4Entegrasyon

Instagram, X, YouTube OAuth bağlantıları, yayın kuyruğu, yeniden deneme, gerçek URL'ler, Web Push ve e-posta bildirimleri, zamanlanmış işler.

Kabul testi: her platformda gerçek bir test paylaşımı (onayınızla) ve URL'nin geri yazılması.

Faz 5Zekâ

Zaman Makinesi, Proje Hafızası özetleri, Fırsat ve Çakışma Zekâsı, veriye dayalı asistan, haftalık/aylık raporlar, finans grafikleri (TRY/USD/EUR).

Faz 6Cila

PWA kurulum, çevrim dışı kuyruk, mobil etkileşimler, performans, güvenlik denetimi, yedek/geri yükleme testi.
